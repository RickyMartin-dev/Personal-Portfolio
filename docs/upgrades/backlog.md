# Upgrade backlog

This backlog is intentionally small and evidence-oriented. Run `./scripts/project suggest-upgrades` before adding a new item.

| State | Upgrade | Evidence needed | Owner | Recheck |
| --- | --- | --- | --- | --- |
| candidate | Recheck external agent and project research | `./scripts/project research <slug> <question>` plus dated source notes | maintainer | monthly or on tool change |
| candidate | Measure time to first verified change for an adopting project | baseline task and repeatable evaluator | adopting project owner | before considering orchestration |

Do not delete rejected ideas; archive them with the reason and evidence so future agents do not rediscover the same dead end.
