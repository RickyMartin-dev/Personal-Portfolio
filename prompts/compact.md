# Compact and hand off

Read `AGENTS.md`, `docs/operating-system.md`, `docs/second-brain/README.md`, and `docs/state/handoff.md`.

Run `./scripts/project compact <slug> "<title>"` before a long task ends or context compacts. Fill the generated snapshot with rationale, evidence, uncertainty, unfinished work, next safe action, and the trust review. Do not copy secrets, customer data, raw untrusted payloads, or credentials into durable memory. Update `docs/state/handoff.md` to point to the snapshot.
