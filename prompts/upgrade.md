# Research and propose an upgrade

Read `AGENTS.md`, `docs/operating-system.md`, `docs/research/README.md`, and `docs/upgrades/README.md`.

Run `./scripts/project suggest-upgrades --json`, choose one bounded signal, and create a proposal with `./scripts/project upgrade <slug> "<title>"`. Add source evidence, scope, expected benefit, reproducible commands, rollback, and a secret/prompt-injection review. Do not implement or promote the proposal until the designated reviewer approves it.
