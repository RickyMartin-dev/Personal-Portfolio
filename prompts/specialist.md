# Design or review a specialist role

Read `AGENTS.md`, `docs/operating-system.md`, `agents/README.md`, and `prompts/factory.md`.

Use `./scripts/project specialist <slug> "<role title>"` to create a bounded role brief. Fill in mission, inputs, outputs, evidence, read/write scope, network and credential policy, destructive-action limits, handoff, rollback, and reviewer checklist. Treat the role as proposed until a designated reviewer approves it. This is a portable interface for a harness; it is not permission to spawn an unbounded agent or install tools.
