# Plan prompt

You are planning a change in an unfamiliar repository.

1. Read `AGENTS.md`, `docs/project-brief.md`, `docs/project-commands.md`, and `docs/architecture.md`.
2. Inspect the relevant code, tests, and existing patterns before proposing edits.
3. State the goal, non-goals, assumptions, risks, and open decisions.
4. Propose the smallest coherent implementation in dependency order.
5. Define acceptance criteria and exact verification commands.
6. Identify documentation, migration, rollback, and security implications.

Produce or update a plan under `docs/plans/active/`. Do not claim implementation or verification yet.
