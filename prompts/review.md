# Review prompt

Read `AGENTS.md` before reviewing the current diff.

Review the current diff against the user request, active plan, architecture, quality bar, and security boundaries.

Look for correctness bugs, missing tests, broken failure handling, data or permission leaks, secret exposure, compatibility regressions, stale docs, and unnecessary scope. Cite file paths and line numbers when possible. Order findings by severity. If there are no actionable findings, say so and name the evidence inspected. Do not edit files unless explicitly asked.
